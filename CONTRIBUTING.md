# Contributing

Contributions should make the repository easier to use as a shared research and design resource.

## Add A New Example

1. Add the screenshot or other artifact to `assets/snippets/`.
2. Use a descriptive filename with the feature code when possible, for example `U6-Headers-04.png`.
3. Add the example to the relevant feature page under `Examples`.
4. Include the source service, capture date, and a short note about what the feature demonstrates when known.

## Add Or Revise A Feature Page

Each feature page should keep this shape:

- Title with the feature code.
- Category and subcategory where relevant.
- Affordance mapping.
- Description.
- Why it may support serendipity.
- Design considerations.
- Examples.

## Evidence Standard

When adding examples, distinguish between:

- Observable interface evidence, such as a visible header, collection, search box, or recommendation row.
- Documented system behavior, such as personalization, curation, or collaborative filtering.
- Inference, such as likely personalization based on wording like "for you."

This distinction matters because the repository is meant to support experiments and reproducible analysis.
