# Contributing

We welcome contributions of new examples of already cataloged serendipity affordance features or additional features.
Before contributing either, please create an issue, following one of the templates provided. 

## Add A New Example

1. Add the screenshot or other artifact to `assets/snippets/`.
2. Name the file with the source followed by all relevant feature tags and feature names, for example `IMDB-U6-Headers-U8-Emphasis.png`.
3. Add the example to the relevant feature page under `Examples`.

## Add Or Revise A Feature Page

Each feature page should keep this shape:

- Title with the feature code.
- Category.
- Affordance mapping.
- Description.
- Why it may support serendipity.
- Design considerations.
- Examples.
