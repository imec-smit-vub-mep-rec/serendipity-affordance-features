# U3 Multimedia

**Category:** User interface  
**Affordance mapping:** Contrast

Multimedia as a user-interface feature refers to how media elements such as covers, thumbnails, trailers, previews, or audio samples are displayed.

## Why It May Support Serendipity

Media can create visual or auditory contrast in otherwise repetitive recommendation lists. A cover, still, preview, or clip can make an item stand out and invite inspection.

## Design Considerations

- Treat media visibility as an experimental manipulation: shown versus hidden, large versus small, static versus playable.
- Ensure media does not crowd out metadata needed to judge relevance.
- Use consistent dimensions so media supports scanning instead of causing layout jumps.
