# U5 Presentation Structure

**Category:** User interface  
**Affordance mapping:** Cross-contacts, Explorability

Presentation structure describes how recommended or browsable items are arranged, for example as single lists, multiple rows, grids, carousels, clusters, shelves, feeds, or mixed modules.

## Why It May Support Serendipity

The arrangement of items can create cross-contacts between genres, topics, sources, or recommendation logics. Multiple structures may invite users to move away from a single ranked path.

## Design Considerations

- Compare single-list and multi-list layouts when testing this feature.
- Label structures clearly enough for users to understand why items are grouped.
- Avoid layouts where visual prominence is mistaken for relevance unless that is intentional.
