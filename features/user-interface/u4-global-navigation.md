# U4 Global Navigation

**Category:** User interface  
**Affordance mapping:** Accessibility, Exposure, Pointers

Global navigation includes persistent menus, tabs, sidebars, primary links, and other interface-level routes that remain available across the system.

## Why It May Support Serendipity

Global navigation makes sections of the environment accessible and repeatedly visible. It can point users toward areas they did not intend to visit while keeping routes available during other tasks.

## Design Considerations

- Make broad exploratory routes visible without competing with the user's current task.
- Include navigation labels that reveal the catalogue's conceptual structure.
- Consider whether persistent navigation increases divergent paths, not only task efficiency.
