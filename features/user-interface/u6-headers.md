# U6 Headers

**Category:** User interface  
**Affordance mapping:** Pointers

Headers are labels, titles, row names, section headings, module labels, and similar text that indicates what a set of items or actions represents.

## Why It May Support Serendipity

Headers act as pointers. They can help users interpret why a group of items appears, what route they might follow next, or what kind of unexpected relation is being surfaced.

## Design Considerations

- Use headers to disclose the logic of a recommendation module or collection.
- Keep labels specific enough to invite action.
- Test alternate wording when the same item set can be framed in different ways.
