# U1 Metadata

**Category:** User interface  
**Affordance mapping:** Slowability

Metadata as a user-interface feature refers to the visible presentation of item attributes, such as title, creator, date, genre, price, rating, format, or short description.

## Why It May Support Serendipity

Visible metadata can slow users down just enough to inspect an item rather than skip past it. Extra descriptive cues may help users recognize unexpected relevance.

## Design Considerations

- Decide which metadata belongs in list views, cards, detail pages, and comparison views.
- Keep the hierarchy scannable so metadata supports inspection without becoming visual noise.
- Test whether adding metadata changes dwell time, clicks, saved items, or reported serendipity.
