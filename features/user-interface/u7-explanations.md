# U7 Explanations

**Category:** User interface  
**Affordance mapping:** Explorability, Pointers

Explanations tell users why an item, list, route, or recommendation is shown, such as "because you liked..." or "popular in this collection."

## Why It May Support Serendipity

Explanations can point users toward a relationship they did not previously see. They can also invite exploration by making recommendation logic inspectable.

## Design Considerations

- Distinguish explanation from persuasion: the explanation should help users decide and explore.
- Reveal useful relations without implying certainty about the user's taste.
- Consider testing explanation presence, specificity, and placement separately.
