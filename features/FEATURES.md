# Browse By Feature

This tree organizes the repository by affordance features: concrete content, interface, and information-access elements that may help recommender systems support serendipitous encounters.

Each feature page gives a definition, its mapped serendipity affordance(s), a short explanation of why it may support serendipity, design considerations, and example snippets.

Content features describe the item data and knowledge structures available in the recommender system.
