# C1 Core Metadata

**Category:** Content  
**Affordance mapping:** Diversity

Core metadata describes an item's basic attributes, such as title, author, publisher, producer, abstract, release year, price, actors, platform, series, or similar domain-specific fields.

## Why It May Support Serendipity

Richer item metadata makes a catalogue more legible and varied. It gives users more potential hooks for noticing difference, similarity, or unexpected relevance beyond the primary recommendation score.

## Design Considerations

- Include metadata that helps users distinguish items at a glance.
- Prefer domain-specific fields over generic labels when they carry real exploratory value.
- Avoid overwhelming compact recommendation surfaces with metadata that belongs on detail pages.
