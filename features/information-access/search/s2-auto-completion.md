# S2 Auto-Completion

**Category:** Information access  
**Subcategory:** Search  
**Affordance mapping:** Accessibility, Explorability, Pointers, Cross-contacts

Auto-completion offers query suggestions, entity matches, categories, or predicted terms while a user types.

## Why It May Support Serendipity

Suggestions can point users toward possible searches, categories, or items before they have fully specified their intent. This can create cross-contacts between the user's partial query and the system's vocabulary.

## Design Considerations

- Separate query completions, category suggestions, and item suggestions when the interface mixes them.
- Consider whether suggestions are personalized, popular, semantic, or spelling-based.
- Treat ranking, timing, and suggestion diversity as measurable variables.
