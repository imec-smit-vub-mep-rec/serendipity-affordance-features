# S1 Search Engine

**Category:** Information access  
**Subcategory:** Search  
**Affordance mapping:** Accessibility, Pointers

A search engine lets users query the catalogue directly through keywords, facets, filters, or other search controls.

## Why It May Support Serendipity

Search makes specific spots accessible, but search results can also point users toward related items, categories, or terms they did not initially seek.

## Design Considerations

- Consider the visibility and placement of the search entry point.
- Log queries and result interactions when search is part of a serendipity study.
- Make result snippets useful enough for users to notice unexpected relevance.
