# B4 User Profiles

**Category:** Information access  
**Subcategory:** Browsing  
**Affordance mapping:** Cross-contacts, Slowability, Exposure, Pointers

User profiles are pages or views showing a user's consumed, purchased, rated, saved, reviewed, or contributed items.

## Why It May Support Serendipity

Profiles expose other people's traces and can create cross-contacts between users and items. A user's own profile can also resurface forgotten items, while another user's profile can become a route into unfamiliar material.

## Design Considerations

- Decide which profile elements are public, private, or selectively shared.
- Make profile activity navigable when it can lead to items, lists, or tags.
- Consider ethical and privacy implications before using profile data experimentally.
