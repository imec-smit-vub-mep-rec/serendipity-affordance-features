# B2 Breadcrumb Trails

**Category:** Information access  
**Subcategory:** Browsing  
**Affordance mapping:** Accessibility, Slowability, Pointers

Breadcrumb trails show a user's current location in a hierarchy or route, such as `Home > Books > Fiction > Historical`.

## Why It May Support Serendipity

Breadcrumbs provide a clear path back to broader categories and can slow navigation into inspectable steps. They also point users toward parent categories that may contain unexpected items.

## Design Considerations

- Ensure each breadcrumb level is clickable when it represents a valid route.
- Use readable hierarchy labels rather than internal taxonomy codes.
- Compare breadcrumb presence against direct navigation when testing discoverability.
