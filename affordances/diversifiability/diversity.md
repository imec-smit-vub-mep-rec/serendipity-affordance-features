# Diversity

**Serendipity affordance family:** Diversifiability  
**Definition:** Multiple potentials, for example diverse or heterogeneous content.

Diversity concerns the range of possible items, interpretations, media types, metadata fields, or user perspectives available in an environment. Features mapped here can stimulate serendipity by making the catalogue feel less uniform and by giving users more varied hooks for unexpected relevance.
